# NeRF
NeRF (Sinirsel Işıma Alanı / Neural Radiance Fields), farklı açılardan çekilmiş 2 boyutlu fotoğrafları kullanarak gerçeğe yakın 3 boyutlu sahneler ve nesneler oluşturan bir yapay zeka teknolojisidir. Klasik 3D modellemeden farklı olarak nesnenin içini ve ışık alımını öğrenerek yepyeni açıardan kusursuz görüntüler üretir.
